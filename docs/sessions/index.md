# Sessions

One file per working session: `YYYY-MM-DD-<short-topic>.md`.

## Before closing a session

1. Add a session summary in this folder with a descriptive name:
   - What we accomplished
   - Design decisions made
   - Files changed
   - Blockers or issues found
   - Next steps
2. Track open work (blockers, next steps) as GitHub issues, not only in the session file.

Do **not** write session progress, feature status, or next steps into `CLAUDE.md`. It holds durable guidance for agents only.
